# TriScribe v0.1.6

首个公开测试版本，面向需要普通话、香港粤语、英语和中英夹杂输入的 macOS 与 Windows 用户。

## 亮点

- SenseVoice 本地离线识别，支持普通话、粤语、英语自动判断。
- 严格离线隐私模式默认开启，不上传录音和转写内容。
- 新增可关闭的“口述标点符号”，默认开启。
- 口述“逗号、句号、问号”等时，以用户明确说出的标点为准。
- 修复模型标点和口述标点相邻时出现 `，，`、`。，` 的问题。
- 新安装默认使用 `Minimal` 悬浮窗，也可切换到 Live 实时文字预览。
- 支持简体／繁体、粤语口语／书面输出、自定义词汇和语气词整理。
- 可选 DeepSeek 等 OpenAI 兼容 API 后处理；严格离线模式下不会调用。

## 下载与安装

### macOS（Apple Silicon）

下载 `TriScribe_0.1.6_macOS_AppleSilicon.dmg`，打开后把 TriScribe 拖入“应用程序”。首次启动需要授予麦克风和辅助功能权限。

如果 macOS 阻止首次启动，请在 Finder 中按住 Control 点击应用并选择“打开”，或在“系统设置 → 隐私与安全性”中选择“仍要打开”。覆盖安装新测试版后，可能需要重新开启一次辅助功能权限。

### Windows（x64）

下载并运行 `TriScribe_0.1.6_Windows_x64_Setup.exe`。如果 SmartScreen 出现保护提示，请选择“更多信息 → 仍要运行”。适用于 Windows 10 / 11 x64。
