# TriScribe 验收测试计划（V0.1）

## 1. 验收目标

在完全断网状态下，验证 macOS 与 Windows 能录音、自动判断普通话/香港粤语/英语、完成转写并粘贴到当前输入框；同时量化准确率与速度，而不是只验证“有输出”。

## 2. 测试语料

每种语言至少 60 条，总时长至少 30 分钟；须取得说话者授权。

- 香港粤语：至少 6 位香港本地说话者，覆盖不同年龄与男女声；包含纯粤语、粤英夹杂、常见语气词。
- 普通话：至少 4 位说话者，覆盖轻度南方口音及正常语速。
- 英语：至少 4 位说话者，优先覆盖香港英语口音及品牌/产品名。
- 长度分层：3–10 秒、10–30 秒、30–120 秒、2–5 分钟各占一定比例。
- 场景分层：安静办公室、笔记本内置麦克风、耳机麦克风、轻度风扇/键盘噪声。
- 术语集：甲方提供不少于 100 个人名、品牌名、地名和行业术语，至少一半放入完整句子。

语料必须有逐字人工标注。粤语口语模式按粤语原词标注，例如“我今日唔得闲”；书面模式另建目标稿，不与口语准确率混算。

## 3. 指标与建议门槛

| 指标             | 计算范围                |                               V0.1 建议门槛 |
| ---------------- | ----------------------- | ------------------------------------------: |
| 普通话 CER       | 汉字级编辑距离          |                                       ≤ 10% |
| 香港粤语 MER     | 汉字/英文词混合编辑距离 |                                       ≤ 12% |
| 英语 WER         | 英文词级编辑距离        |                                       ≤ 15% |
| 三语自动判断     | 每条主语言标签          |                                       ≥ 95% |
| 术语准确率       | 指定术语完全匹配        |                未加词典 ≥ 80%；加词典 ≥ 95% |
| 实时率 RTF       | 处理耗时 ÷ 音频时长     | Apple Silicon ≤ 0.5；主流 Windows CPU ≤ 0.8 |
| 快捷键到开始录音 | 人工/日志测量           |                                    ≤ 300 ms |
| 断网可用性       | 禁网后全流程            |                                   100% 通过 |

以上门槛是项目验收建议，不是当前已实测成绩。低配置机器应单列结果，不把不同硬件平均在一起。

## 4. 必测用例

1. 自动模式连续说普通话、粤语、英语各 20 条。
2. 同一句内中英夹杂，例如品牌、职位、型号与英文缩写。
3. 简体/香港繁体切换后重复同一批粤语与普通话。
4. 粤语口语模式输出原声；书面模式验证语义未被改变，并标记实验性规则覆盖率。
5. 输入 `陈晓明→陈小明`、`ChatGPT` 等词典项，比较开启前后。
6. 连续录音 3–5 分钟，检查丢句、乱序、内存增长与粘贴完整性。
7. 完全关闭网络后重启应用并完成识别。
8. macOS 撤销麦克风/辅助功能权限，Windows 关闭麦克风/输入权限，检查引导与错误提示。

## 5. 放行规则

- P0：崩溃、录音泄露、联网后才能识别、转写内容错贴到其他窗口——任一出现即不放行。
- P1：任一核心语言低于门槛、长录音丢段、简繁设置失效——修复并复测后放行。
- 书面粤语模式不作为原声转写准确率的替代指标；任何改写都需抽样人工审核。
